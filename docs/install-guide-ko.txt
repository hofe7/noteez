Noteez 0.0.1 — 지인 테스트용

설치하기
1. Noteez-0.0.1.dmg 파일을 열어 주세요.
2. Noteez.app을 옆의 Applications 폴더로 드래그해 주세요.
   기존 Noteez가 실행 중이면 메뉴바에서 ‘Noteez 종료’를 먼저 선택해 주세요.
3. 응용 프로그램 폴더의 Noteez를 실행해 주세요.
4. 메뉴바에 스티커 아이콘이 나타나면 준비가 끝났습니다.
   Noteez는 메뉴바 앱이라 Dock에 아이콘이 나오지 않습니다.

처음 실행이 차단될 때
이 테스트 빌드는 아직 Apple 공증을 받지 않았습니다.
전달받은 Noteez를 실행한 뒤 macOS가 차단하면 창을 닫고,
시스템 설정 → 개인정보 보호 및 보안에서 Noteez의 ‘확인 없이 열기’를
선택한 후 안내에 따라 다시 실행해 주세요.

사용해 보기
- 메뉴바 → 새 메모: 아이디어, 회의록, 할 일을 적습니다.
- 메모 아래 ‘연결·묶음’: 다른 메모를 검색해 참고 연결을 만들거나,
  묶음을 새로 만들고 이동할 수 있습니다.
- 메뉴바 → 전체 보기: 메모들을 모아 보고 여러 개를 선택해 정리합니다.
- 자동 추천을 쓰려면 메뉴바 → AI 연결 모델…에서 Small 모델을 받아 주세요.
  모델 다운로드에는 인터넷이 필요합니다. 직접 메모하고 정리하는 기능은
  모델을 받기 전에도 쓸 수 있습니다.

단축키
⌘⇧N        새 메모
⌘⇧Space    빠른 캡처
⌘⇧K        검색
⌘⇧G        전체 보기

데이터와 피드백
메모는 Mac에 저장됩니다. 메뉴바에서 Noteez 백업 저장… 또는 Markdown
내보내기를 사용할 수 있습니다.
자동 추천은 아직 놓치거나 잘못 제안하는 경우가 있습니다.
‘메모하기 불편했던 순간’, ‘연결·묶음 설정에서 헷갈린 부분’,
‘함께 추천됐으면 했던 메모’를 알려주시면 개선에 도움이 됩니다.
업무 메모를 그대로 보내기보다는 내용을 가린 예시로 알려주세요.
