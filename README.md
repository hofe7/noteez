# Noteez

> 맥 스티커처럼 가볍고 예쁜 메모 보드. 그냥 적으면, 필요할 때 찾아주고 "내가 한 일"로 정리해준다.

*(작업명. Brain Inbox에서 출발해 가볍게 다시 깎은 버전)*

---

## 한 줄

흩어지게 적은 메모를 **가벼운 컬러 스티커 보드**에 던져두면, AI가 조용히 뒤에서 검색·연결·"내가 한 일" 정리를 받쳐준다.

핵심은 두 가지를 동시에 잡는 것:

```
(가볍고 예쁜 캡처)  ×  (소환 + 내가 한 일 정리)
   매일 오는 이유          깊은 가치
```

둘 중 하나가 0이면 전체가 0이다.

---

## 문제

나는 메모를 여기저기 흩어지게 적는다. 회의 내용, 떠오른 생각, 투두, 전화하다 급하게 갈긴 것. 카톡·메모앱·포스트잇에 따로따로.

그래서 두 가지가 자주 아프다.

- **곤란할 때 못 찾는다.** 적어둔 건 아는데 너무 많아서 못 찾는다.
- **"내가 뭐 했지"에 답이 없다.** 분기·연말 평가에 한 일을 내야 하는데 재구성이 안 된다. 그냥 궁금할 때도 답이 없다.

기존 메모앱은 *적기*는 쉽게 해주지만, 쌓인 다음에 *다시 쓰는* 건 안 도와준다.

---

## 포지셔닝 — 무엇을 파는가

간판은 **메커니즘이 아니라 결과**다.

- ❌ "AI가 메모를 분류·정리·연결해드립니다" → 아무도 안 산다. (이미 많이 시도됐고 무겁다)
- ✅ "그냥 적어. 곤란한 순간엔 바로 찾아주고, 평가 철엔 네가 한 일이 알아서 정리돼 나온다."

분류·연결은 **간판이 아니라 엔진**이다. 약속(소환·정리)을 지키려고 뒤에서 돌아갈 뿐, 사용자에게 파는 건 결과다.

헤드라인 후보:

1. 오늘 대충 적은 메모가, 분기 보고서가 됩니다.
2. 그냥 적어. 네가 한 일은 우리가 기억한다.
3. 필요한 순간, 흩어진 메모가 답으로 나온다.

---

## 쓰는 맛 (제일 중요)

맥 기본 스티커가 레퍼런스. 가볍고, 단순하고, 배울 게 없다. 노션처럼 각 잡는 사람은 소수다.

- **그냥 적는다.** 폴더·태그·프로젝트 선택 없음. 결정할 게 없는 게 가벼움의 핵심.
- **필요한 기능은 한 번에.** `-` 치면 체크박스, 단축키로 취소선. 손 안 떼고.
- **색깔별로 쫙 펼치고, 접는다.** 보드처럼.
- **예쁨은 장식이 아니라 retention 엔진.** 쓰는 게 기분 좋아야 매일 온다.

### 찾는 방식은 두 개가 공존한다

- **공간 기억(사람):** "왼쪽 위 노란 거였는데" 보드에서 눈으로.
- **의미 검색(AI):** 어딨는지 모를 때 AI가 소환.

가벼운 사람은 보드만 써도 되고, 많아지면 AI가 받쳐준다.

---

## AI는 조용한 조수다 (주인이 아님)

원칙:

1. **보드는 사용자 것.** AI가 스티커를 멋대로 재배치·색칠하지 않는다.
2. **품질이 존재감을 결정한다.**
   - 확신 낮음 → 아예 안 보임
   - 중간 → 연관검색어처럼 슥, 회색으로 옆에
   - 아주 높음(드뭄) → 살짝 더 강하게, 작은 모먼트처럼
3. **모먼트는 아껴 쓴다.** 매번 팡팡 = 싸구려. 가끔 진짜 소름일 때만.
4. **연결은 백그라운드 자동, "연결" 버튼은 선택.** 버튼 안 눌러도 제품은 완벽히 돈다. (안 그러면 "정리 안 해도 됨"이 거짓말)
5. **제안은 AI, 확정은 사람.**

### 투두와 보고가 맞물리는 지점

- **체크박스 투두** → 시스템이 확실히 아는 깨끗한 데이터. "내가 한 일" 보고에 그대로.
- **문장으로 적은 것**("민수한테 견적서") → 그때만 AI가 "이거 할 일?" 슬쩍 제안.

가벼우려고 넣은 체크박스가 보고서의 재료층이 된다. 일석이조.

### 연결과 묶음

수락한 연결 하나 = 엣지 하나다. 시스템은 의미상 가까운 메모를 조용히 추천하고,
사용자가 확정한 연결만 전체 보기의 묶음으로 남는다. 잘못된 추천은 숨길 수 있고
메모 내용이 바뀌면 다시 평가된다.

## 구현 단계

각 단계가 그 자체로 쓸 만해야 다음으로 간다.

```
v1  스티커 보드 + 로컬 DB       ✓
v2  의미 검색 (온디바이스)        ✓
v3  연결 추천 + 묶음             ✓
v4  "내가 한 일" 보고           ✓
v5  Markdown/Notion/Obsidian 이동성 ✓
```

**왜 AI를 빼고 시작하나:**

1. 진짜 위험("매일 쓰고 싶을 만큼 기분 좋은가")을 제일 싸게 검증한다.
2. 예쁨·인터랙션은 내가 아끼는 craft고 학습 목표와 맞는다.
3. 내가 먼저 2주 쓰면 스티커가 쌓여서, AI를 얹을 때 cold-start가 저절로 죽는다. (내가 1번 사용자)

## 기술 메모 (가볍게)

- **플랫폼:** Flutter (Mac 먼저 → iOS/Android/Windows). 렌더링을 직접 소유해 전 플랫폼 동일하게 예쁘게.
- **상태/저장:** 메인 프로세스가 권위자. Drift(SQLite)에 스티커, 연결,
  임베딩 캐시, 추천 숨김, Markdown 원본 대응을 저장한다.
- **에디터:** Flutter Quill은 편집 표현으로만 사용하고, 영속 데이터는
  `Block` sealed class(텍스트/할 일/이미지)로 유지한다.
- **검색/연결:** multilingual-e5-small ONNX 모델을 온디바이스에서 실행한다.
  메모 내용은 외부로 나가지 않는다.
- **멀티윈도우:** 메인/스티커/전체 보기/보고 창이 IPC로 상태를 주고받는다.
- **이동성:** 표준 Markdown + YAML front matter + Obsidian wiki link.
  대량 ZIP 압축 해제는 별도 isolate에서 실행한다.

기술은 commodity. 진짜 실력은 **언제 입을 다물지(절제)**.

## 실행 (개발)

```bash
flutter run -d macos
```

## Markdown·Notion·Obsidian 이동

메뉴바 스티커 아이콘에서 실행한다.

- **Markdown 파일 가져오기:** 선택한 여러 `.md`/`.markdown` 파일을 서랍으로 가져온다.
- **Markdown 폴더 가져오기:** Obsidian vault 등 하위 폴더까지 탐색한다.
- **Notion ZIP 가져오기:** Notion의 Markdown & CSV export ZIP을 압축을
  수동으로 풀지 않고 바로 선택한다.
- **모든 메모 내보내기:** 메모별 Markdown, `_assets` 이미지, `[[연결]]`을
  함께 내보낸다. 결과 폴더는 Obsidian에서 바로 열 수 있다.

같은 원본을 다시 가져오면 중복을 건너뛴다. 원본만 바뀐 경우에는 기존 메모를
안전하게 갱신하고, Noteez에서도 편집된 충돌 상태면 둘 다 보존한다.

## 설치 (배포본 DMG)

`tool/make_dmg.sh` 로 `dist/Noteez.dmg` 를 만든다. 아직 **미서명/미노타라이즈**라
(Apple Developer ID 미보유) 받는 쪽에서 처음 한 번 Gatekeeper를 통과시켜야 한다:

1. DMG 열고 **Noteez** 를 **Applications** 로 드래그.
2. 처음 실행: **우클릭 → 열기 → "열기"** (더블클릭은 차단됨), 또는 시스템 설정 →
   개인정보 보호 및 보안에서 "확인 없이 열기".
3. 또는 터미널 한 줄: `xattr -dr com.apple.quarantine /Applications/Noteez.app`

> 메뉴바 앱이라 독에 아이콘이 없다 — 실행 후 **메뉴바 스티커 아이콘**과
> 글로벌 단축키(⌘⇧N 새 메모, ⌘⇧Space 캡처, ⌘⇧K 검색, ⌘⇧G 전체 보기)로 쓴다.

널리 배포할 때가 되면 $99/년 Apple Developer Program으로 codesign + notarize 하면
이 단계가 사라진다 (코드 변경 없이 `make_dmg.sh` 에 서명 단계만 추가).
